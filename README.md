# LLM Eval Cookbook

A small library of reusable evaluation recipes: exact match, rubric grading,
preference comparison, pairwise ranking, and JSON-schema checks.

## Quick Start

```bash
pip install -e ".[dev]"
python examples/run_eval_recipes.py
pytest
```
